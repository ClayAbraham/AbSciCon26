# GitHub Pages Test Folder

This folder contains a simple static test page for GitHub Pages.

## Files

- `index.html` is the page entry point.
- `styles.css` holds the page styling.

## Publish options

1. Push this repository to GitHub.
2. In the repository settings, open **Pages**.
3. Choose the branch you want to publish from.
4. Set the folder to `/docs`.

If you want, I can also turn this into a fuller project landing page with links to your generated heatmaps and outputs.
